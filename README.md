# Meine Tools

Kleine Web-Apps fürs iPad, veröffentlicht über GitHub Pages.

| Tool | Ordner | Wofür |
|---|---|---|
| Klausur-Notenrechner | [`notenrechner/`](notenrechner/) | Klausurnote aus Aufgaben in Notenpunkten (0–15), frei in Blöcken gewichtbar |
| Gesamtnote | [`gesamtnote/`](gesamtnote/) | Gesamtnote aus gewichteten Teilnoten, z. B. mündlich und schriftlich |

**Auf dem iPad nutzen:** Adresse des Tools in Safari öffnen → Teilen → „Zum Home-Bildschirm“. Danach startet das Tool im Vollbild wie eine App.

Alle Eingaben bleiben auf dem Gerät. Es wird nichts hochgeladen.

Neue Tools und Änderungen entstehen mit Claude. Alle Regeln und Hintergründe stehen in [`CLAUDE.md`](CLAUDE.md).
