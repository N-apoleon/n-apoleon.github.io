Klausur-Notenrechner

Notenpunkte 0–15 pro Aufgabe antippen. Aufbau und Gewichtung legst du unter „Klausur einrichten“ fest.

Klausur einrichten

Aufgaben in einem Block teilen sich das Gewicht des Blocks zu gleichen Teilen. Eine Aufgabe, die allein zählt, bekommt einen eigenen Block.

Blockpunkte = Durchschnitt der Aufgaben im Block. Gesamtpunkte = Summe aus Blockpunkte × Blockgewicht, gerundet auf ganze Notenpunkte (ab ,5 aufgerundet). Gesamtprozent = Gesamtpunkte / 15. Deine Einrichtung bleibt auf diesem Gerät gespeichert.
